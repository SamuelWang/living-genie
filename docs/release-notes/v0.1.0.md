# Release notes — v0.1.0

Living Genie's first release stands up the core diary app: register an account, log in, and
keep a private, dated diary with rich markdown formatting and inline images — all running
locally via Docker.

## What's new

- **Accounts** — register with an email and password, then log in/out. Diary data is private to
  your account.
- **Diary entries** — create, view, edit, and delete entries with a title, date, and markdown
  content.
- **Rich-text editor** — format entries with headings, lists, task lists, tables, code blocks,
  links, and text color; insert images by upload or drag-and-drop.
- **Multi-language UI** — switch between Traditional Chinese (default) and English at any time.
- **Runs locally via Docker** — `docker compose up` brings up the frontend, backend, and
  PostgreSQL database, with data persisting across restarts.

## Not included yet

No AI/LLM features are part of this release — no chat, no retrieval over your diary content.
That begins in v0.2.0. See [../roadmap.md](../roadmap.md) for what's next.
